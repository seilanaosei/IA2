ÍRIS IA — protótipo PWA para celular

O que funciona:
- Interface instalável e adaptada ao celular.
- Chat usando Gemini API com chave inserida pelo usuário.
- Atalhos para ferramentas públicas de geração/edição de imagem e música.
- Pré-visualização local de imagem e cópia de descrições.

Limitações importantes:
- Não é uma IA própria treinada do zero.
- A chave Gemini fica no armazenamento local deste navegador. Não coloque sua chave em site público compartilhado.
- O chat depende da cota gratuita e disponibilidade da API Gemini.
- Imagens e músicas são abertas em serviços externos; cada serviço pode limitar uso, exigir login ou ficar indisponível. A prévia local não modifica a imagem.
- Não há como garantir alta qualidade, tudo grátis e ilimitado ao mesmo tempo.

Como usar:
1. Hospede estes arquivos em um endereço HTTPS (por exemplo, um host estático).
2. Abra o endereço no Chrome Android.
3. Para o chat, toque em "Obter chave grátis", crie uma chave no Google AI Studio, cole e salve.
4. Para instalar, abra o menu do Chrome e use "Instalar app" ou "Adicionar à tela inicial".
